一、快速上手
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. 把要解密的音乐文件放到 input 文件夹里
  2. 双击运行 Kugo-Music-Converter.exe
  3. 输入数字选择功能，按回车执行


二、功能选项说明
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [1] 完整流程（含批量转MP3）
      自动完成全部步骤：复制文件 → 解密 → 转MP3 → 自动清理

  [2] 完整流程（仅解密，不转MP3）
      只解密不解码，保留原始音频格式（FLAC/OGG）

  [3] KGM 专用流程
      只处理 .kgm/.kgma/.vpr 和加密的 .flac，不处理 .kgg

  [4] 仅解密 .kgg → .ogg
      专门解密 .kgg 格式文件，输出为 .ogg

  [5] 仅批量转 MP3
      将输出目录中的 FLAC/OGG 批量转为 MP3（保留封面和歌曲信息）

  [0] 退出


二·五、图形界面版（可选）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  不喜欢数字菜单？可以运行图形界面（先安装一次依赖）：

      pip install pywebview
      python gui.py

  界面只有三个功能：

  1. 添加文件 —— 点击"添加文件/添加文件夹"选择，或直接把文件、
     文件夹拖进窗口（拖文件夹会自动扫描里面的音乐文件）。
     这一步只是暂存到列表，不会马上复制到 input 文件夹。

  2. 开始处理 —— 右下角这一个按钮就会执行完整流程：
     复制到 input/ → 解密 → 转MP3 → 自动清理。
     窗口底部有流程进度状态条，点"处理日志"页签可看实时日志。

  3. 清理缓存 —— 左下角的按钮。删除 input/ 和 kgm-vpr-out/
     里的音乐文件（保留 ffmpeg.exe 和 批量转MP3.bat），
     点击后会先弹窗确认再删除。

  界面会自动跟随系统的深色/浅色主题。


三、支持的文件格式
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  .kgg      → 酷狗加密格式，解密为 .ogg
  .kgm      → 酷狗加密格式，自动解密
  .kgma     → 酷狗加密格式，自动解密
  .vpr      → 酷狗加密格式，自动解密
  .flac     → 如果文件是加密的（伪装的KGM），会自动重命名后解密
  .kgg.flac → 手机酷狗下载的加密文件（实为KGG伪装），自动识别并解密为 .ogg


四、常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Q: .kgg 文件解密失败，提示"缺少解密密钥"？
  A: 先用酷狗音乐客户端播放一次该文件，获取密钥缓存后再试。

  Q: 手机酷狗下载的 .kgg.flac 文件能处理吗？
  A: 能。直接放进 input 文件夹即可，工具会自动识别（实为 KGG 格式伪装）
     并还原为 .kgg 解密，无需手动改名。注意解密前仍需先用酷狗客户端
     播放一次该文件以获取密钥。

  Q: 解密后的文件在哪里？
  A: 所有输出都在 kgm-vpr-out 文件夹里。

  Q: unlockKuGoWin 提示不支持大文件？
  A: 该工具仅支持 78MB 以下的文件，超大文件无法处理。

  Q: 运行完后根目录会有残留文件吗？
  A: 选择完整流程（选项1或2）会自动清理，无需手动删除。
